# Referencia Técnica

Estas notas de referencia explican las mejores prácticas y métodos para trabajar con **ChatGPT Work**, **Skills de la Empresa**, **Desarrollo Guiado por Especificaciones (Spec-Driven Development)** y **Agentes Conversacionales**.

---

## Métodos y Guías Internas

- **ChatGPT Work Walkthrough**: Conexión segura de carpetas locales, prompts con resultados claros (Outcome/Input/Contenido/Restricciones/Verificación) e iteración progresiva.
- **Skills Architecture**: Estructura de `SKILL.md` (YAML header + Markdown body), activación automática por `description` y tokens del Design System de InkaFarm.
- **Spec-Driven Development**: Flujo de 4 pasos para definir la especificación v1 antes de codificar, delimitación de alcance y criterios de aceptación verificables.
- **Agentes & UI en Lovable**: Prototipado rápido de dashboards ejecutivos, integración de datos sintéticos JSON y cableado de chat conversacional.
