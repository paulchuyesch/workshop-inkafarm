# Workshop InkaFarm

**Categoría:** Taller · Beginner | **Formato:** Video | **Duración:** 10 pasos | **Precio:** Gratis

Este repositorio contiene la plataforma e-learning del **Workshop InkaFarm**, un taller práctico sobre **ChatGPT Work**, **Skills de Análisis de Datos**, **Spec-Driven Development**, **interfaces interactivas en Lovable** y **Agentes Conversacionales autónomos**.
